# How to open the onboarding one-pager

Clicking the `.html` file in GitHub or Cursor only shows **code**. That is normal. Use one of these ways to see the real page:

## Easiest (in Dawn)

1. Start Dawn (`npm run dev` inside `dawn-scaffold`).
2. Open this link in your browser:

**http://127.0.0.1:3000/onboarding**

or

**http://127.0.0.1:3000/hospital-onboarding-one-pager.html**

## If you cannot run Dawn

1. Find the file: `dawn-scaffold/public/hospital-onboarding-one-pager.html`
2. Right-click it → **Open with** → Chrome / Edge / Safari
