Stage checklist

1. Interest M1 · Ready for onboarding

  • Demo complete
  • LOI signed
  • EAA signed

2. Preparation M2 · Ready for kickoff

  • Kickoff meeting invite sent
  • Kickoff meeting scheduled

3. Kickoff meeting M3 · 1st practice complete

  • Welcome deck / set expectations
  • Admin account created + login successful
  • Platform overview
  • Managing admin (site profile, users, notifs)
  • Study opportunities, forms & requests
  • AI suggest-answer context
  • Investigators + ethics committees setup
  • Practice study opportunity and feasibility

4. Go live M4 · First real pilot done

  • Training guide shared
  • Hospital sets up profile in next 7 days (+ follow-up Qs)
  • ONWARD publishes profile once agreed
  • (Optional) Hospital runs a pilot feasibility with CRO

5. Follow-up Commercial transition

  • 2-week check-in (questions, issues, requests)
  • 1-month / 2-month / 3-month check-ins
  • Transition to commercial agreement
